# Go Discount Calculator

This is my first project in the Go programming language.

The project is a simple discount calculator that calculates the final price of a product after applying a discount percentage.

## Concepts Used

In this project, some basic Go programming concepts are used, including:

- Variables
  
- Functions
  
- Conditional statements (`if`)
  
- Control structures (`for`)
  
- User input with `fmt.Scan`
  
- String formatting with `fmt.Sprintf`

  ## Program Features

- Get product name from the user
  
- Get product price
  
- Get discount percentage
  
- Calculate the final price
  
- Display the result to the user
  
- Option to continue or exit the program

## Purpose of the Project

The purpose of this project is to practice the basic concepts of the Go language and become familiar with building simple CLI programs.
